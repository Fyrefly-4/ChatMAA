## Documentation language

- Write human-facing project documentation primarily in Simplified Chinese, unless the user or specification requires otherwise. Prefer natural, reader-friendly wording and explain unfamiliar technical terms when helpful.
- Keep code, identifiers, API and configuration names, protocol names, official names, and necessary English terms in their original form.
- Agent-only or machine-readable content may use the language and format best suited to its purpose. In mixed documents, apply the Chinese-language rule only to human-facing prose.

## Code Review Rules

- Write all code review feedback in Simplified Chinese, including review summaries, inline comments, issue titles, problem descriptions, and suggested changes.
- Preserve technical terms, code identifiers, commands, file paths, and necessary source quotations in their original form.
