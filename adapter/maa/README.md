# MAA 单次执行能力

正式单次执行函数位于 `native.py`：先识别当前环境，再执行一次明确参数的任务，正常结束后独立识别战后环境。`core.py` 封装公共 ABI，`contract.py` 解释已确认完成量，`replay.py` 为离线回放。

相较原型复用层，本步骤放开固定三次上限至 MaaCore int 范围，仍限定 1-7、不吃药不碎石和 series=1；显式指定失败节点识别资源，避免连续加载时查找带前缀的不存在模板。战斗结果先保存，识别失败不抹掉已确认完成量；停止未确认时保持未知，设备仍需核对。前后识别仅观察，不点击或导航；识别依据最长使用五秒。

这是可独立验证的执行函数，尚无 HTTP 受理与持久化控制服务。配置类提供固定版本、Windows 和窗口参数；启动配置检查不连接游戏。

在仓库根目录运行 `python -m unittest discover -s adapter/maa/tests -v`。测试覆盖参数、回调证据、单次执行、连续加载、前后识别和异常停止，替换 MaaCore 边界，不操作真实游戏。需 Python 3.12；此阶段检查仅依赖标准库。真实执行必须另行明确环境、次数及现场交接。
