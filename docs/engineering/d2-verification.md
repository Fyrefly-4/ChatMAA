## 实际通过的通路

同一 Backend、Adapter 和数据目录依次完成：扫描 → 次数 → 材料 → 开战后停止 → 退出交接，全程不依赖模型。

| 操作 | 观察结果与解释 |
|---|---|
| 库存扫描 | Depot 最终 done、任务结束、自动化停止均有记录，用户确认库存核对；后置识别回到首页，随后接受刷图。缺失项仍未知，不推断全材料覆盖或零库存 |
| 次数任务 | count=1，确认 1 次成功、固源岩 1，精确结算，环境可再次受理 |
| 材料任务 | 固源岩目标 1，实验 max_count=2；实际 1 次、固源岩 1 后停止，未用完次数上限，随后环境可受理。支持本样本由材料阈值结束；本轮没有观察到超额 |
| 停止任务 | count=2，首个可观察周期开始后发 stop；开始 1、确认完成 0、未结算 1，结果保留下界、环境 needs_check |
| 退出 | Backend 报告证据交接完成、自有 Adapter 已退出；未关闭游戏或模拟器，未把未结算战斗改成完成 |

停止任务是本轮合计第三场。StartButton2 完成先于 stop；执行端从停止请求到确认不再运行约 0.297 秒，客户端观察约 0.536 秒（含 HTTP／轮询）。这些是该样本的测量，不是时限保证。停止 MAA 自动化不会取消已经开始的游戏内战斗，用户确认程序结束时第三场已开始，与日志中未结算周期一致。该场最终掉落和资源消耗不由自动化停止记录推断。

stop-after 截图为黑帧，不能作为游戏现场证据；本项现场判断采用用户观察，时序采用执行日志。报告生成器现明确显示已开始和未结算周期，避免把“成功完成 0 次”误读为“没有开战”。

## 离线证据与未验证范围

| 检查 | 覆盖及边界 | 对后续建设的影响 |
|---|---|---|
| 脱敏实机回调回归 | [四类摘录](../../adapter/maa/fixtures/d2-mumu/README.md)保留实际顺序及字段；库存数量替换，不能据样例复核玩家数量 | D3 可复用实际反馈形状与已知／未知语义 |
| 掉落异常注入 | 在已采集顺序上删除 StageDrops 或注入 UNKNOWN_DROP，经正式 native 循环确认发出 AsstStop、停止后不放行；仅 MaaCore 边界为替身 | 异常处理路径有验证；未测自然 OCR 故障及其实际延迟，不提供零额外批次保证 |
| 倍率与超额 | 离线覆盖周期去重、累计一致性、固定倍率映射、目标不整除及材料超额；实机只有单倍 | 不新增单倍产品白名单；其他组合的实际可用性仍依赖 Core／关卡，不能宣传已实测 |
| 部分完成 | 实机停止留下未结算；离线覆盖限次未达材料目标、结算缺失和不确定性 | 理智不足未现场触发，不编造对应结束原因；上层按完成事实计算剩余 |
| 同步／恢复 | 真实 HTTP＋双库回放、受控异步接管、丢回执、多目标、重建服务状态、同目录重启、幂等与退出均有回归 | 恢复只查原记录，不自动续刷或重发；放行不改变旧结果 |
| 桌面端 | 旧路径与新增共用逻辑保留，专项新能力实机后补 | 按已批准边界不作为 D2 门禁，不把 MuMu 结果算作桌面证据 |

这些限制没有要求改变三种操作或上层职责。固定 MuMu 的正常操作和停止事实已成立；未实测倍率、自然故障概率与性能上界不阻止 D3 依据当前确定参数契约建设，但不能成为新的支持承诺。若后续观察到计数不可信、异常不停止或需要改变 Core 行为，应重新审阅相应能力，不以本轮通过覆盖反例。

## D3 可使用的结果样例

下表是相关字段摘录，不是完整 HTTP 响应；库存 72 是脱敏示例值，不是本轮玩家库存。

| 场景 | 可用字段 | 上层处理 |
|---|---|---|
| 扫描 | inventory_result.items={"30012":72}，complete=true，certainty=recognized，missing_items=unknown | 只使用可靠扫描依据；未出现材料不能默认为 0 |
| 次数完成 | count_result={value:1, certainty:exact, issues:[]}，automation_stopped=true，device=ready | 成功次数与目标比较；检查同步完整、无冲突后才形成精确结论 |
| 材料完成 | material_result.items["30012"]=1，certainty=exact，threshold_reached=true | 这是本次收获；补库存还需 Backend 加初始库存并标注推算 |
| 开战后停止 | count_result.value=0，certainty=lower_bound，started_cycles=1，unsettled_cycles=1，device=needs_check | 表达已确认量和未知部分，不补刷、不因自动化已停放行 |

方案确认、会话、目标差额计算、材料与关卡适用性、资料来源仍归 D3 及后续阶段；新确定参数能力未自动开放给旧模型工具。D2 不承担完整自然语言、业务方案或新页面验收。
